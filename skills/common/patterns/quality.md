# Quality Contract

1. Define 2-5 observable acceptance criteria before producing or reviewing.
2. Hard criteria and executable checks outrank reviewer preference.
3. Cite `path:line`, command output, screenshot, or exact artifact evidence for
   every defect and verdict.
4. Separate facts, inferences, and preferences; challenge weak premises and say
   what evidence would change the conclusion.
5. Use beauty only after correctness: fit, coherence, economy, proportion,
   legibility, and honesty. Translate taste into an actionable defect.
6. Bound revisions. Rework only cited gaps; report `PARTIAL` at the cap.
7. The delivering agent independently verifies the final artifact. Subagent
   approval and consensus are advisory.
