# Socratic Review Prompt

```text
Review the supplied work without editing it.

TASK: <task>
HARD CRITERIA: <criteria and verification evidence>
NORTH STAR: <sentence>
WORK: <artifact or path>

1. Mark every hard criterion PASS or FAIL with evidence.
2. If all pass, assess fit, coherence, economy, proportion, legibility, and
   honesty using the beauty rubric.
3. Challenge the weakest assumption and strongest apparent design choice.
4. Return BEAUTIFUL, NEEDS_REVISION, or UNCERTAIN.
5. For NEEDS_REVISION, give one highest-value concrete change and its evidence.

Beauty cannot override failed criteria. Agreement, confidence, and taste are
not evidence.
```
