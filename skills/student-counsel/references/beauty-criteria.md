# Beauty Rubric

Beauty is shorthand for qualities that make correct work feel inevitable rather
than patched together. Score each dimension `clear`, `defect`, or `not-applicable`
with evidence.

- **Fit:** the work serves its actual purpose and audience.
- **Coherence:** parts follow a small, consistent set of ideas.
- **Economy:** every element earns its cost; no needless abstraction or prose.
- **Proportion:** attention and complexity match importance and risk.
- **Legibility:** structure exposes intent and supports local reasoning.
- **Honesty:** assumptions, uncertainty, limitations, and failure modes are
  represented accurately.

Translate aesthetic language into a concrete defect. “Ugly” is invalid;
“three exception branches obscure one missing invariant” is actionable.

Task emphasis:

- Code: invariants, names, abstraction cost, error behavior, local reasoning.
- Writing: argumentative structure, specificity, proportion, necessary words.
- Plans: dependencies, assumptions, auditability, recovery paths.
- Teaching: learner starting point, step continuity, examples, stopping point.

Hard acceptance and verification always outrank this rubric.
